# Relief Studio — обязательное чтение для ИИ-агента

Перед любыми изменениями прочитай этот файл и `docs/AI_HANDOFF.md`. Они описывают уже реализованный интерфейс, производительный цикл рендера, ограничения SVG-импорта и правила проверки.

## Быстрый старт

```bash
npm install
npm test
npm run build
npm run dev -- --host 127.0.0.1 --port 5175
```

Основной исходный код находится в `src/`, тесты — в `tests/`, публичные SVG-данные и примеры — в `public/`, production-артефакты — в `dist/`.

Не удаляй и не обходи тесты импорта масок, металлических контуров, качества PNG, истории, перетаскивания источников и производительности без отдельной проверки поведения в браузере.
