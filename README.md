# Relief — студия объёма

У источника света доступны «Мягкий Screen» и «Сочность на свету» (по умолчанию 15%). Это направленное высветление цвета эмали; оно сохраняется в рецепте и экспорте. «Только физический свет» отключает наложение. Форму объекта это не меняет.

Выпуклость эмали по умолчанию — 1 px. Высота, фаска, выпуклость, матовость и глянец сохраняются после перезагрузки. Для рендера удаляются почти совпадающие замкнутые дубликаты обводки поверх контура с заливкой, если совпадают цвет, толщина и большая часть площади. Исходный SVG и проверка его импорта сохраняются отдельно; открытые линии и самостоятельные обводки эта очистка не удаляет.

По умолчанию включён пресет «Чистые цвета · профиль ImageGen»: нейтральный ключевой свет 120%, заполняющий свет 65%, яркость 115%, затемнение 30% и сочность теней 35%. Приглушённые цветные заливки эмали мягко высветляются с сохранением оттенка. Белый, серый, чёрный и уже яркие пигменты остаются нейтральными или сохраняют исходный цвет. Выбранный вручную цвет слоя используется напрямую.

Прежние сохранённые настройки один раз переходят на более светлый баланс. Положения источников сохраняются; слабое затемнение не усиливается. Последующие правки сохраняются как обычно, источники остаются редактируемыми.

Локальный инструмент на Three.js для превращения плоских векторных значков в объёмные эмалевые объекты. В комплекте — пять исходных макетов из Figma и изображения ImageGen для сравнения.

## Запуск

```sh
npm install
npm run dev -- --port 5174
```

Откройте http://127.0.0.1:5174/. Для готовой сборки: `npm run build`, затем `npm run preview`.

## Как настраивать

1. Выберите значок или загрузите свой SVG. Всегда используется физическая трассировка лучей.
2. **Высота бортика** определяет перепад между металлом и эмалью и длину падающей тени.
3. **Скругление края** меняет физическую форму фаски, а **выпуклость эмали** — кривизну внутренней поверхности.
4. **Мягкость источника** задаёт его физический размер: 0.3 — резкая тень, 4.0 — широкая мягкая полутень. При изменении размера сохраняется мощность источника. Размер источника меняет настоящие падающие тени; результат постепенно очищается от зерна. **Заполняющий свет** управляет глубиной теней; меньшие значения дают больше контраста.
5. Поверните объект кнопкой «Посмотреть объём» или мышью. «Спереди» возвращает ортографическую камеру для сравнения с исходником.
6. В разделе «Цвета, материал и высота слоёв» можно перекрасить каждый нижний слой и бортик, поменять материал и поднять конкретную область. «Все бортики» перекрашивает металл сразу.

## Несколько источников

Нажмите «+ Добавить» в разделе света (до восьми источников). Выберите источник в списке или нажмите его пронумерованную точку на сцене. Точку можно перетаскивать мышью или пальцем: источник перемещается вслед за ней, в том числе при повёрнутом макете. При перетаскивании вращение макета временно отключается. Положения и параметры автоматически сохраняются в этом браузере, остаются общими при смене макета и входят в рецепт. Каждый источник имеет собственные мощность, цвет, мягкость, направление и угол над поверхностью; его можно выключить или удалить. 0° соответствует свету сверху, 180° — снизу. Источники за кадром отмечены у края изображения и имеют соответствующую подсказку. Точки можно скрыть.

Скрытая вкладка приостанавливает накопление. Для настройки можно выбрать 128 сэмплов, для финального просмотра — 512 или 1024; все варианты используют трассировку лучей.

## Сохранение

- **PNG:** 1024 × 1024. Рендер накапливает 512 сэмплов. Точки источников в PNG не попадают. «Без фона» сохраняет прозрачность; при этом тени между частями значка остаются, а внешняя принимающая плоскость удаляется из сцены и расчёта лучей. Режим включён по умолчанию.
- **3D-модель:** GLB с геометрией и материалами, без студийной сцены.
- **Рецепт:** JSON со всеми источниками, цветами и высотами слоёв. Откройте его через «Загрузить SVG», чтобы восстановить настройку встроенного макета.

Исходные векторы в Figma не меняются. PNG — растровый результат рендера; редактируемая 3D-геометрия сохраняется отдельно в GLB.

## Геометрия и освещение

Студия читает исходные SVG-обводки с их шириной, открытыми и замкнутыми участками, порядком слоёв и векторными масками. Металлические контуры объединяются в программе до построения объёма. Цветные области вырезаны по видимым границам, поэтому исходные стыки векторных фрагментов не создают отдельные фаски. Металл получает экструзию с округлённой фаской, построенной из пересечений внутренних полос. Фаска сохраняет исходный силуэт и отверстия, в том числе на узких стыках. Для цветных областей рассчитывается гладкая выпуклая поверхность с закреплёнными краями; её треугольная сетка имеет настоящие нормали.

Освещение рассчитывает `three-gpu-pathtracer`: прямоугольный ключевой источник, заполняющий источник, окружение, шесть отражений луча. Это прогрессивный path tracing. Шум при небольшом количестве сэмплов ожидаем; для финального просмотра предусмотрены 512 и 1024 сэмпла.

## Импорт

Поддерживаются SVG со сплошными заливками и обводками. Обводки объединяются в металл, перекрытия заливок вычитаются. Растровые изображения и градиенты при импорте отклоняются. Материалы и глубины определяются по простым правилам, затем доступны для ручной корректировки. Из плоского SVG нельзя однозначно восстановить реальные высоты и форму из ImageGen: совпадение требует настройки.

Белые заливки получают тот же материал эмали, что и цветные. Цвет не превращает белую деталь в хромированный шарнир. Работа требует WebGL 2; скорость накопления зависит от видеокарты.

## Источники библиотек

- Three.js: https://threejs.org/docs/pages/ExtrudeGeometry.html
- SVGLoader: https://threejs.org/docs/pages/SVGLoader.html
- GPU path tracer: https://github.com/gkjohnson/three-gpu-pathtracer

Все макеты и настройки обрабатываются локально. Для студии не нужны API-ключи или генератор изображений.

## Проверки

При запущенном сервере разработки откройте `/tests-render.html`: проверка редактирования источников, сохранения настроек, импорта SVG и физической трассировки. `/tests.html` проверяет геометрию пяти макетов, отверстия SVG и экспорт GLB.

## Источник затемнения

Кнопка **«+ Затемнение»** добавляет тёмную точку. Её можно перетаскивать независимо от света; **сила затемнения** и **ширина перехода** регулируются в той же панели. По умолчанию затемнение идёт снизу слева, оставляя верх справа светлее. Это плавный переход яркости на металле и эмали, который сохраняет блики и расположение контактных теней. Он сохраняется в рецепте, PNG и материалах GLB.

Градиенты рассчитываются без промежуточного округления в 8 бит. Текстуры и атлас трассировщика используют 16-битный формат с плавающей точкой, чтобы на тёмной эмали не появлялись широкие полосы. При экспорте GLB текстуры отдельно переводятся в sRGB PNG с минимальным нейтральным дизерингом; материалы рабочего рендера при этом не меняются. Проверка `tests-gradients.html` сравнивает точность старого и нового атласа на GPU.

`/tests-rims.html` сравнивает нативный SVG, разобранные контуры и только верхнюю поверхность фаски при 1024×1024: пять макетов, стыки открытых линий, маска с неравномерным масштабированием и поворотом, отверстия even-odd. Тест проверяет исходный контур без художественного утолщения. Допуск растеризации — 2 пикселя около исходной границы. `?bevel=2` проверяет максимальную фаску.

## Проверка загружаемого SVG

При загрузке студия сравнивает плоские контуры и цвета с независимой отрисовкой SVG браузером при 1024×1024. Расхождение вне двухпиксельной зоны сглаживания останавливает импорт с сообщением об ошибке. Это проверка с конечной точностью, а не гарантия поддержки любого SVG или математического совпадения каждой точки. Неподдерживаемые эффекты нужно преобразовать в векторные контуры. Исходник виден в небольшом сворачиваемом окне под выбором макета.

Свой SVG можно выбрать кнопкой «Загрузить свой SVG» под окном оригинала или перетащить на это окно / область рендера. Файлы обрабатываются локально.

Бортики в рендере расширяются равномерно на 25% относительно ширины исходной обводки — приближение к референсам ImageGen. Соприкасающиеся бортики плавно объединяются; такое соединение не уменьшает толщину всего макета. Если утолщение закрыло бы исходное отверстие, общая поправка ограничивается, чтобы сохранить его открытым. Исходный SVG и его проверка выполняются до этой поправки.

В настройках затемнения есть «Мягкий Multiply»: плавное умножение с деликатным подъёмом яркости и насыщенности теней эмали. «Сочность в тени» по умолчанию 20%; 0% или «Обычное затемнение» возвращают нейтральное затенение. Белые области остаются нейтральными. Выбор сохраняется вместе с источником в браузере и рецепте. `/tests-darkness.html` проверяет текстуры, переключение, белую эмаль и неизменность металла.

Соприкасающиеся эмалевые заливки без обводки используют общее поле выпуклости и нормалей. Цветовой стык не создаёт бортик или отдельную впадину. Ручное поднятие слоя по-прежнему задаёт отдельную высоту.

На этом Mac сервер 127.0.0.1:5174 запущен через LaunchAgent `local.relief.studio`: запускается при входе в macOS и перезапускается после сбоя. Он работает независимо от терминала и Codex, пока Mac включён и не спит. Конфигурация: `~/Library/LaunchAgents/local.relief.studio.plist`.

Все сплошные SVG-заливки, в том числе чёрные, серые и белые, по умолчанию являются эмалью на одной высоте. Цвет не используется как признак металла. Металлические бортики создаются из обводок; материал отдельного слоя можно назначить вручную.

В разделе «Поверхность» есть «Яркость блика на кромке» (по умолчанию 55%) и «Ширина светлой полоски» (35%). Они управляют узкой светлой полосой на скруглении бортика со стороны источника света. Полоса задаётся цветами вершин существующей поверхности; физическое освещение продолжает влиять на металл. 0% яркости убирает добавленную полосу. Геометрия при регулировке не меняется. Цвета передаются в трассировщик в формате RGBA с непрозрачной альфой. Настройки сохраняются в браузере, рецепте, PNG и GLB.

Профиль vivid-colour-v2 усиливает цветные пигменты, включая светло-голубые с максимальным синим каналом, и уменьшает белёсое отражение эмали. Стандартные заполняющий свет и яркость — 80% и 140%. При обновлении заменяются только прежние стандартные 65% и 115%; собственные значения и источники остаются сохранены.
