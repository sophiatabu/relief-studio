# Relief Studio

Браузерная студия для создания объёмных значков из SVG. Превращает плоскую иллюстрацию в рельефный объект с металлическими контурами, цветной эмалью и настраиваемым освещением.

[Открыть студию](https://sophiatabu.github.io/relief-studio/)

## Возможности

- Загрузка собственного SVG и работа с библиотекой из 93 иллюстраций.
- Отдельный редактор деталей: назначение ролей, изменение цветов, скрытие элементов и вырезание областей.
- Настройка металлической обводки, скосов, высоты и выпуклости эмали.
- Управление источниками света, бликами, тенями и затемнением с отдельным влиянием на металл и цветные поверхности.
- Сравнение текущего рендера с готовыми референсами.
- Сохранение настроек проекта и экспорт результата в PNG и GLB.

Рендер использует Three.js и прогрессивную GPU-трассировку лучей. Изображение постепенно очищается от шума; скорость зависит от видеокарты, размера превью и сложности модели. Для работы требуется WebGL 2.

SVG и настройки обрабатываются в браузере. Для рендера не нужны API-ключи или генератор изображений.

## Работа со SVG

Импортёр обрабатывает векторные заливки, обводки, маски, обрезку, градиенты и эффекты SVG. Поддержка отдельных конструкций развивается: наличие функции не означает, что любой SVG уже обрабатывается без ошибок.

Импорт сопоставляет полученные контуры с независимой отрисовкой исходника браузером. Ошибки геометрии, окраски или материалов следует исправлять в инструменте на конкретном исходном файле.

Роли материалов редактируются отдельно от исходной окраски. Металлические контуры должны соединяться без внутренних швов, а цветная эмаль — сохранять свой оттенок при настройке света.

## Экспорт и проекты

Целевой формат обычного PNG-экспорта — прозрачное изображение **1024 × 1024** без выбора дополнительных размеров. GLB предназначен для сохранения геометрии и материалов. Файл проекта сохраняет исходный SVG и настройки для продолжения работы.

Функциональные требования и фактический статус исправлений описаны в документации. Локальное изменение, загрузка кода в репозиторий и публикация GitHub Pages — отдельные этапы.

## Локальный запуск

Требуется Node.js, совместимый с используемой версией Vite.

```bash
npm install
npm run dev -- --host 127.0.0.1 --port 5175
```

Откройте адрес, который выведет сервер разработки.

```bash
npm test
npm run build
npm run preview
```

Исходный код находится в `src/`, SVG-библиотека и публичные ресурсы — в `public/`, проверки — в `tests/`, сборка — в `dist/`.
